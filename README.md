# Number Squares Dictionary Generator

A simple Python program that generates a dictionary containing ascending integers and their corresponding square values. The program asks the user to enter a limit, then uses a custom function and a `for` loop to create key-value pairs, where each key represents an integer starting from 1 and each value represents its square. This project is ideal for beginners who want to practice dictionaries, functions, loops, and mathematical operations in Python.

## Features
- Accepts a user-defined limit for the dictionary.
- Generates ascending integers starting from 1.
- Calculates the square of each integer using `pow()`.
- Stores each integer and its square as a key-value pair in a dictionary.
- Uses a custom function to generate and return the dictionary.

## How to Run
1. Make sure Python 3 is installed.
2. Run the script:
   ```bash
   python number_squares_dictionary.py
   ```
3. Enter the desired limit.
4. View the generated dictionary containing each number and its square.
